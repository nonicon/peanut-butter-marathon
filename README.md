An entry for the [make.fun bounty "The One-Line Laugh"](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f): one funny line, at most 200 characters, judged pairwise by a house judge.

## The line

> My fitness tracker buzzed to congratulate me on hitting my daily step goal while I was violently shaking a jar of peanut butter.

## How it works

`main.py` writes that single line to `/output/entry.txt` — the artifact the house judge reads. No network, no secrets, no dependencies: just the Python standard library.

```sh
python3 main.py
```
